开机自动运行（不用开黑色窗口）

    
打开后，每次开机程序会自己在后台运行，不显示黑色窗口，也就不会被误关。局域网里的人只要你电脑开着就能打开。你自己要用时，在浏览器打开 http://127.0.0.1:8765/（建议存成书签），或者双击程序文件夹里的 START_BACKGROUND.bat。

    

      
      
    

    
现在就想改成后台运行：点「退出程序」，再双击 START_BACKGROUND.bat。电脑睡眠时别人也打不开，可以在 Windows 设置 → 系统 → 电源里，把「插入电源时进入睡眠」改成「从不」（屏幕照常熄灭没关系）。

    

  

  

    
云端只读副本

    
把数据加密后放一份到网上（GitHub Pages，免费），你的电脑关着别人也能用一个固定网址查看看板、价格图表和全部记录。云端只能看，不能录入；看到的是你最后一次上传的数据。每次保存或修改后，程序会在你停下来两分钟后自动上传（一小时最多约 10 次）。

    
第一次怎么设置（大约 5 分钟）
    
      
  1. 打开 github.com，注册或登录一个免费账号。
    2. 
      
  2. 右上角「+」→ New repository：名字填 mica-prices，选 Public（数据是加密的，公开也看不到内容），勾上 Add a README file，点 Create repository。
    3. 
      
  3. 在这个仓库页面点上方 Settings → 左边 Pages：Source 选 Deploy from a branch，Branch 选 main 和 /(root)，点 Save。
    4. 
      
  4. 右上角头像 → Settings → 左边最下面 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token：
        名字随便填；Expiration 选最长（到期后回来换一个）；Repository access 选 Only select repositories，选中 mica-prices；
        Permissions 里点 Add permissions，选 Contents，设成 Read and write（只给这一项就够）；点 Generate token，复制那串以 github_pat_ 开头的字。
    5. 
      
  5. 回到这里：仓库填「你的用户名/mica-prices」，上传密钥粘贴刚才那串字，再设一个云端查看密码，点「保存」，再点「立即上传」。
    6. 
      
  6. 第一次上传后等一两分钟，把下面出现的网址和查看密码发给要看的人。

    
换成自己的网址（比如 prices.micasupply.ca）
    
      
  1. 登录管域名的地方（micasupply.ca 在 Namecheap：Domain List → Manage → Advanced DNS）→ Add new record：Type 选 CNAME，Host 填 prices，Value 填 你的GitHub用户名.github.io（全小写），点绿色勾保存。
    2. 
      
  2. 回到这里，「自己的网址」填 prices.micasupply.ca，点「保存」，再点「立即上传」。
    3. 
      
  3. 打开 GitHub 仓库 → Settings → Pages，确认 Custom domain 显示 prices.micasupply.ca，检查通过后（几分钟到一小时），勾上 Enforce HTTPS。
    4. 
      
  4. 之后用 https://prices.micasupply.ca 打开。换网址后，每个人要重新输一次查看密码。
